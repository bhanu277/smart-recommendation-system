## 🏗 System Architecture

User Input
(Movie Name + User ID)
        ↓
Content-Based Filtering
        ↓
Similarity Computation
        ↓
Hybrid Recommendation Engine
        ↓
Top Movie Recommendations
        ↓
Frontend Display
